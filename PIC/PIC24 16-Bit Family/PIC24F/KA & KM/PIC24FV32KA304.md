## Notes

- Exposed Pad `-` The exposed pad on the underside of the device is connected to **`Vss`**.

- Alternate Multiplexing `-`There is alternate multiplexing for **`SDA1 (ASDA1)`** and **`SCL1 (ASCL1)`** when the **`I2CSEL`** Configuration bit is set.

- Maximum Voltage / Tolerance `-` PIC24F32KA304 device pins have a maximum voltage of **`3.6V`** and are **`not 5V tolerant`**.

### ⚡ Power
* `Vdd` (Positive Core Power Supply)
* `Vss` (System Ground)
* `AVdd` (Analog Positive Power Reference)
* `AVss` (Analog Ground Reference)
* `VCAP` (Internal Regulator Filter Capacitor Pin)

### 📌 Port
* **Port A:** `RA0`, `RA1`, `RA2`, `RA3`, `RA4`, `RA5`, `RA6`, `RA7`, `RA8`, `RA9`, `RA10`, `RA11`
* **Port B:** `RB0` through `RB15`
* **Port C:** `RC0` through `RC9`

### 🛠️ ICSP (In-Circuit Serial Programming)
* `MCLR/Vpp` (Master Clear / Programming Voltage Input)
* `PGEC` (In-Circuit Emulator/ISCP Manager Clock Lines)
* `PGED` (In-Circuit Emulator/ISCP Manager Data Lines)

### 📡 Protocol
* `UART` (Universal Asynchronous Receiver-Transmitter)
* `SPI` (Serial Peripheral Interface)
* `I2C` (Inter-Integrated Circuit)
* `SDA1` (I2C1 Serial Data Line)
* `SCL1` (I2C1 Serial Clock Line)

### ⚙️ Peripheral
* `ADC` (Analog-to-Digital Converter)
* `AN0` through `AN15` (ADC Analog Input Channels)
* `comparator` (Analog Voltage Comparators)
* `Input Capture` (Timer-driven input event capture)
* `Output Compare` (Timer-driven output generation / PWM)
* `CN` (Change Notification Interrupt Pins)
* `CTED` (Charge Time Measurement Unit - CTMU Edge Input Pins)
