🔀 Peripheral Pin Select (PPS) Reference

PIC32MZ2048EFM064 has 34 remappable pins. CAN has NO fixed pins — entirely PPS assigned.

PPS Summary for 64-pin EFM: 34 RPx pins cover CAN TX/RX, UART TX/RX, SPI MOSI/MISO/SS, OC, IC, INT1–4, U_CTS/RTS. I²C, SPI Clock (SCKx), INT0 are fixed. Unlock with SYSKEY before writing RPxR or peripheral input registers.
▶ Output PPS — Assign Signal to Pin
// Unlock PPS
SYSKEY = 0xAA996655;
SYSKEY = 0x556699AA;
CFGCONbits.IOLOCK = 0;

// C1TX → RPD1 (Pin 49)
RPD1R = 0x0F;

// UART1 TX → RPD2 (Pin 50)
RPD2R = 0x01;

// Re-lock
CFGCONbits.IOLOCK = 1;
SYSKEY = 0x00000000;
◀ Input PPS — Assign Pin to Peripheral
// C1RX ← RPG7 (Pin 5)
C1RXR = 0x06; // RPG7 code

// UART1 RX ← RPG9 (Pin 10)
U1RXR = 0x01; // RPG9 code

// SPI1 MISO ← RPB2 (Pin 14)
SDI1R = 0x04; // RPB2 code

// INT1 ← RPD0 (Pin 46)
INT1R = 0x03; // RPD0 code
⚠ Fixed (non-remappable): I²C SDA/SCL pins (RG7=SDA4, RG8=SCL4, RF4=SDA5, RF5=SCL5, RD9=SDA1, RD10=SCL1, RD2=SDA3, RD3=SCL3). SPI clock pins: SCK2=RG6(4), SCK3=RB14(29), SCK4=RD10(44), SCK1=RD1(49). INT0=RD0(46). MCLR=Pin9. OSC1/OSC2=Pins 31/32.

💾 Memory Architecture — PIC32MZ2048EFM064

All addresses are virtual (KSEG0/KSEG1). Use KVA_TO_PA() for DMA/NVM physical addresses.

⚡ Program Flash
2 MB
Dual-panel live update. NVM self-write capable.
16 KB erasable pages (128 rows).
128 row × 512 bytes = 65536 bytes/page.
Use last page for config: 0x9D1F0000.
KSEG0: 0x9D000000–0x9D1FFFFF
Phys: 0x1D000000–0x1D1FFFFF
🗂 Data SRAM
512 KB
Single-cycle at 200 MHz. Stack + heap + DMA buffers.
DMA: __attribute__((coherent))
Uncached alias for DMA at KSEG1.
KSEG1: 0xA0000000–0xA007FFFF
Phys: 0x00000000–0x0007FFFF
🔒 Boot Flash
160 KB
Config bits + bootloader. DEVCFG3 (FMIIEN=0 for RMII). Device serial: DEVSN0/1.
KSEG1: 0xBFC00000–0xBFC27FFF
Config: 0xBFC0FF40–0xBFC0FFEF
DEVSN0: 0xBFC54020
⚡ L1 Cache
20 KB
16 KB I-Cache (4-way) + 4 KB D-Cache (2-way).
Enable: CHECON.PREFEN = 3.
Flash wait states: CHECON.PFMWS = 2 @ 200 MHz.
CHECON: 0xBF800000
Set PFMWS for Flash wait states
