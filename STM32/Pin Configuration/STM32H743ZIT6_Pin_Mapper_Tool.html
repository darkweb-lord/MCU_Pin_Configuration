About this tool

An offline pin configuration utility for the single-core STM32H7 high-performance line. Pin, ball and alternate-function data is taken from the ST datasheets and cross-checked against ST's published STM32 pin database.

      Use

      Always confirm a final pin assignment against the device datasheet and reference manual before release. Analog-switch pins, oscillator pins and debug pins need particular care.
